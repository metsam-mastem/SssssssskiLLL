# واژه‌نامه

- Agent runtime: چرخه اجرایی عامل، state، provider، tools و policy.
- Background observer: فرایندی که در پس‌زمینه رخدادها را مشاهده و حافظه کاندید تولید می‌کند.
- Context assembly: انتخاب و ترتیب‌دادن پیام خام/خلاصه‌ها برای context مدل.
- Context compaction: کاهش اندازه context فعال با خلاصه‌سازی یا حذف/جایگزینی بخشی از تاریخچه.
- DAG: گراف جهت‌دار بدون دور؛ در LCM برای پیوند خلاصه‌های سلسله‌مراتبی استفاده می‌شود.
- Durable Object: primitive حالت‌دار Cloudflare با عملیات هماهنگ‌شده در سطح object.
- MCP: Model Context Protocol؛ قرارداد کشف و فراخوانی ابزار/منابع/پرامپت.
- Memory attribution: اثبات اینکه نتیجه عامل واقعاً از memory تزریق‌شده استفاده کرده است.
- Memory drift: انحراف عامل به‌علت حافظه نامربوط، نادرست یا قدیمی.
- One-time bearer: اعتبارنامه کوتاه‌عمر و تک‌مصرف برای یک عمل محدود.
- Worktree: checkout مستقل Git متصل به همان repository، مناسب اجرای موازی.
- ELv2: Elastic License 2.0؛ مجوز source-available با محدودیت‌های خاص، از جمله hosted/managed service.
- Mixed-license: مخزنی که اجزا یا assets آن تحت مجوزهای متفاوت هستند.
- Snapshot: مجموعه فایل‌ها و محتوای یک commit/tree مشخص در زمان برداشت.
